# my-sysadmin-scripts

Скрипт мониторинга ресурсов: раз в 10 секунд дописывает в `monitor.log` блок с меткой времени и выводами `free -h`, `df -h`, `uptime`.

## Запуск

```bash
chmod +x script.sh
./script.sh
```

Остановка — `Ctrl+C`: в лог записывается отметка об остановке.

## Настройка

Интервал и имя лог-файла задаются константами `INTERVAL` и `LOG_FILE` в начале `script.sh`.

## Обработка ошибок

если в системе нет `free`, `df` или `uptime`, скрипт завершается с кодом 1;
если нет прав на запись в лог-файл, скрипт завершается с кодом 1;
по `Ctrl+C` или `kill` скрипт корректно завершает работу.
